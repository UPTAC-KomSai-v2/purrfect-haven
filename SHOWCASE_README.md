# Showcase instructions
Notes:
- Make sure you have docker installed in your system.

## Running Purrfect Haven (Web App):
1. cd to the same location as docker-compose
2. Run `docker compose up --build` to build and run the website.
3. When the site is up, simply go to `http://localhost/` or `http://your_ip_here/` and the site will be accessible.
Now the web app is working locally!

Unfortunately since domain names and hosting services cost money, we'll be showcasing through localhost for now.
Though users within the same network can access the website so if ever they're curious, they can just go to `http://your_ip_here/`.
